Checks Selection Guidance

TLS checks only: Use for web/TLS posture monitoring (protocols, certificates, HSTS, ciphers) when mail DNS controls are not in scope.

DNS checks only: Use for mail-domain posture checks (SPF, DKIM, DMARC, MX/WHOIS context) when TLS endpoint scanning is not required.

Both checks: Use for internet-facing domains/hosts where you want complete transport and mail-security visibility.
